# frontend/

Next.js 16 (App Router, TypeScript, Tailwind) untuk PBL DevSecOps.

Cara menjalankan & arsitektur lengkap ada di [`../README.md`](../README.md).

```bash
npm ci
npm run dev    # http://localhost:3000 (/api/* di-proxy ke http://localhost:8000)
npm run build  # build produksi (output: standalone)
```
